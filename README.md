# Paper-latexing

> Are you also worried about not being able to write an attractive *Abstract* and *Introduction*? 😖
> 你也在为写不出吸引人的 *Abstract* 和 *Introduction* 而苦恼吗？

大水漫灌的时代，讲好故事可以帮助我们增加中论文的概率。 众研究生苦于得不到手把手科研全流程教学久矣！ 

## 🎮 Begin 引子

受 **香港科技大学（广州）骆昱宇** 老师团队开源的 **[Supervisor-Skills](https://github.com/HKUSTDial/Supervisor-Skills)** 启发，我自己运用这个 Skill 梳理了一些论文的Introduction，并在每篇论文中总结出写作常用词、经典句式，后续随着项目的逐渐完善，我也会把这些积累封装成一个开源Skill，服务大家写出更 insight & attractive 的 Paper。
